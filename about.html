Hello!

I am Dmitry, embedded software engineer, hardware enthusiast, and embedded software consultant. Here I post various in-depth bits, and project updates.

Consulting / outsourcing / projects

I specialize in bare-metal / RTOS-based embedded software development.

Worked with connectivity devices, various sensors, various MCUs, and things that fly, measure, send, or receive under power, and memory constraints.

I offer

  • Outsource maintenance;
  • Development;
  • Research / consulting;

The best I can help a company with (especially a pure software one) is to bring embedded systems expertise:

  • Consult on early stages of the project, formulate the specs: "what MCU to choose", "how to implement functionality the simplest way possible", "is it possible to do this", "how to distribute the functionality b/w server/device", "how to deliver the firmware updates to the user", "how to protect the firmware". Will avoid the necessity to redo things;
  • Offer a second opinion as a software engineer when working w/ a PCB designer. It will make developing the firmware for the device easier at later stages;
  • Do proper software engineering to a mishandled firmware codebase. Set up proper versioning, sort out branches, merge functionality, and write the guidelines. Makes diving into the code faster for new developers.
  • Coordinate the work, offer mentoring.
  • Maintain a firmware, or write one from scratch.

What I most likely will NOT be able to help a company with:

  • Special in-depth aspects of signal processing, control systems, AI, etc.;
  • Complex hardware design;

Payment scheme:

  • If the task is clear, we use fixed rate. Split the work in billable chunks. Payment upon completion.
  • If not applicable (e.g. research), we agree on a time-based billing;
